# Fishing Pond Generator

Di Unity, jalankan menu **Mancing Cuy > Generate Fishing Pond Scene**.

Generator membuat scene `FishingPond.unity` secara prosedural menggunakan primitive Unity, sehingga tidak membutuhkan aset eksternal atau lisensi tambahan. Scene berisi kolam, air, dermaga, saung, papan nama, jalur masuk, bangku, batu, pohon, kamera, cahaya, dan fog.
